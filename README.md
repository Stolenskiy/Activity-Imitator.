# Activity Imitator

Утиліта, яка імітує людську активність (рух миші, кліки, скрол, навігаційні клавіші) під час довгих автоматизованих тестів у IDE, щоб віддалена сесія (VDI/RDP) або сама IDE не завершувалась через тайм-аут бездіяльності.

## Вимоги

- Python 3.8+
- X11 або Wayland+XWayland (`DISPLAY` має бути встановлений) — рух миші/кліки/навігаційні клавіші йдуть через `pyautogui`, це працює в обох випадках
- Для глобальних гарячих клавіш (`SafetyListener`) на Wayland потрібен доступ до `/dev/input/*`: користувач має бути в групі `input`

## Встановлення

Система (Debian/Ubuntu/Pop!_OS) блокує `pip install` поза віртуальним середовищем (PEP 668), тож використовуйте venv:

```bash
sudo apt-get install -y python3-tk python3-dev   # потрібно для pyautogui (MouseInfo)
sudo usermod -aG input $USER                      # потрібно для глобальних гарячих клавіш (evdev)
# перелогіньтесь (вийти з сесії / зайти знову), щоб членство в групі 'input' набуло сили
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

> **Чому evdev, а не X11-хук:** на Wayland-сесіях (GNOME, Cosmic тощо) композитор навмисно не віддає глобальні події клавіатури X11/XWayland-клієнтам — тому бібліотеки на кшталт `pynput` з X11-бекендом мовчки нічого не ловлять. `evdev` читає сирі події напряму з `/dev/input` (без ексклюзивного захоплення пристрою, тож інші застосунки й далі отримують ці ж клавіші як зазвичай).

## Запуск

```bash
.venv/bin/python activity_imitator.py
```

## Гарячі клавіші

- `Ctrl+Alt+S` — пауза / відновлення
- `Ctrl+Alt+Q` — вихід
- Переміщення курсора у будь-який кут екрана — аварійне переривання (вбудований fail-safe `pyautogui`)

## Безпека

- Курсор рухається лише в центральній зоні екрана (15–85% ширини/висоти), щоб не зачепити системний трей, панель задач чи кнопки вікон.
- Використовуються лише навігаційні/немодифікуючі клавіші (`Shift`, `Ctrl`, `Alt+←/→`, `Page Up/Down`, `↑/↓`, `Esc`) — жодних `Enter`, `Backspace`, `Delete`, `Space` чи алфавітно-цифрових символів, тобто вміст файлів не змінюється.
- Затримки між діями випадкові (5–45 с), без фіксованого періоду.

## Структура коду

- `RandomizationEngine` — випадкові затримки та вибір дії за вагами
- `InputSimulator` — рух миші по кривій Безьє, кліки/скрол, навігаційні клавіші
- `SafetyListener` — глобальні гарячі клавіші паузи/виходу (evdev, пасивне читання `/dev/input`)
- `MainLoop` — головний цикл, консольні логи з таймстемпами
