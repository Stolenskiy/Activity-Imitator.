# Activity Imitator

Утиліта, яка імітує людську активність (рух миші, кліки, скрол, навігаційні клавіші) під час довгих автоматизованих тестів у IDE, щоб віддалена сесія (VDI/RDP) або сама IDE не завершувалась через тайм-аут бездіяльності.

> Агентам і розробникам: точка входу — `AGENTS.md`. Таблиці в цьому файлі звіряються з кодом тестами (`make verify`), тож змінюйте їх разом із кодом.

## Вимоги

- Python 3.10+, Linux.
- Запис до `/dev/uinput`. На сучасних десктопах (systemd-logind) його автоматично отримує користувач, який сидить за комп'ютером; перевірити: `getfacl /dev/uinput`.
- Для гарячих клавіш і автопаузи — читання `/dev/input/*`: користувач має бути в групі `input`.
- Працює і на Wayland, і на X11; XWayland/`DISPLAY` не потрібні.

## Встановлення

Система (Debian/Ubuntu/Pop!_OS) блокує `pip install` поза віртуальним середовищем (PEP 668), тож усе ставиться у `.venv`:

```bash
sudo usermod -aG input $USER   # гарячі клавіші й автопауза (evdev); потім перелогіньтесь
make setup                     # .venv + requirements.txt (потрібна мережа)
make install-launcher          # показує, що буде встановлено (нічого не пише)
make install-launcher APPLY=1  # ярлик на робочий стіл і в меню застосунків
```

> **Чому uinput, а не pyautogui/XTest:** на Wayland (COSMIC, GNOME) XWayland пропускає емуляцію введення через портал «Віддалене керування» і питає дозволу при кожному запуску (як «Невідомий застосунок»). Віртуальні пристрої uinput створюються на рівні ядра: композитор бачить їх як звичайну мишу й клавіатуру, тож жодних діалогів немає. Вказівник абсолютний, і COSMIC відображає його координати на монітор, де зараз курсор.
>
> **Чому evdev, а не X11-хук:** на Wayland-сесіях композитор навмисно не віддає глобальні події клавіатури X11/XWayland-клієнтам — тому бібліотеки на кшталт `pynput` з X11-бекендом мовчки нічого не ловлять. `evdev` читає сирі події напряму з `/dev/input` (без ексклюзивного захоплення пристрою, тож інші застосунки й далі отримують ці ж клавіші як зазвичай).

## Запуск

**Графічний інтерфейс** (рекомендовано; ярлик «Activity Imitator» запускає саме його):

```bash
.venv/bin/python activity_imitator_gui.py
```

- велика кнопка-кільце запускає й зупиняє імітацію, по колу видно відлік до наступної дії;
- статус (Активний / Автопауза / Пауза / Зупинено), остання дія, час роботи, кількість дій;
- **автопауза**: щойно ви торкаєтеся миші, тачпада чи клавіатури, імітація стає на паузу й продовжується сама після періоду бездіяльності (`resume_after` у «Налаштуваннях»);
- таймер тривалості з автозупинкою;
- журнал подій і вкладка налаштувань (див. таблицю «Налаштування»);
- іконка в треї з кольоровим індикатором статусу; закриття вікна не зупиняє роботу (вихід — через меню трею);
- повторний запуск ярлика просто показує вже відкрите вікно;
- кліки й клавіші, які надходять одразу після власних дій імітатора, вікно ігнорує, тож імітатор не натисне власні кнопки.

**Консольний режим**:

```bash
.venv/bin/python activity_imitator.py
```

## Налаштування

Ключі файлу `~/.config/activity-imitator/settings.json` (значення у форматі JSON):

| Ключ | За замовчуванням | Опис |
|---|---|---|
| `min_delay` | `5` | мінімальна пауза між діями, с |
| `max_delay` | `45` | максимальна пауза між діями, с |
| `mouse` | `true` | рух миші |
| `clicks` | `true` | кліки та прокрутка після руху миші |
| `keys` | `true` | навігаційні клавіші |
| `pauses` | `true` | мікропаузи |
| `duration_min` | `0` | тривалість сесії, хв (`0` — без обмеження) |
| `auto_pause` | `true` | автопауза, коли ви працюєте за комп'ютером |
| `resume_after` | `60` | продовжити після стількох секунд вашої бездіяльності |
| `autostart` | `false` | починати імітацію одразу при відкритті |
| `close_to_tray` | `true` | закриття вікна ховає його в трей |
| `tray_hint_shown` | `false` | службове: підказку про трей уже показано |

## Параметри ядра

Константи `activity_imitator.py` (консольний режим; GUI бере інтервали з «Налаштувань»):

| Константа | Значення | Опис |
|---|---|---|
| `MIN_DELAY_SECONDS` | `5` | мінімальна пауза між діями, с |
| `MAX_DELAY_SECONDS` | `45` | максимальна пауза між діями, с |
| `BOUNDING_BOX_MARGIN` | `0.15` | відступ безпечної зони від країв екрана (частка ширини/висоти) |
| `IDLE_RESUME_SECONDS` | `60` | автопауза: продовжити після стількох секунд бездіяльності |

## Гарячі клавіші

| Комбінація | Дія | Опис |
|---|---|---|
| `Ctrl+Alt+S` | `pause` | пауза / відновлення (у GUI: якщо зупинено — запуск) |
| `Ctrl+Alt+Q` | `quit` | вихід (у GUI: зупинка імітації, програма лишається в треї) |

Будь-який рух миші, дотик до тачпада чи натискання клавіші вмикає автопаузу (замість старого fail-safe «курсор у кут», який на Wayland не працював надійно).

## Безпека

- Курсор рухається лише в центральній зоні екрана (відступ `BOUNDING_BOX_MARGIN` від кожного краю), щоб не зачепити трей, панель задач чи кнопки вікон.
- Натискаються лише навігаційні клавіші з таблиці нижче — жодних Enter, Backspace, Delete, Space чи літер і цифр, тож вміст файлів не змінюється.
- Затримки між діями випадкові, без фіксованого періоду (межі — у «Параметрах ядра» та «Налаштуваннях»).
- Імітатор не «бореться» з вами за мишу: якщо ви берете її посеред руху, рух переривається.
- Власні віртуальні пристрої (`Activity Imitator virtual …`) слухач ігнорує, тож імітація не сприймається як ваша активність.

| Код у `SAFE_KEYS` | Клавіші |
|---|---|
| `shift` | Shift |
| `ctrl` | Ctrl |
| `alt+left` | Alt+← |
| `alt+right` | Alt+→ |
| `pageup` | Page Up |
| `pagedown` | Page Down |
| `up` | ↑ |
| `down` | ↓ |
| `esc` | Esc |

## Структура коду

### `activity_imitator.py`

| Клас | Призначення |
|---|---|
| `RandomizationEngine` | випадкові затримки, вибір дії за вагами, безпечна зона |
| `UInputBackend` | віртуальні миша (абсолютні координати) і клавіатура через `/dev/uinput` |
| `InputSimulator` | рух миші по кривій Безьє, кліки/скрол, навігаційні клавіші |
| `SafetyListener` | гарячі клавіші й час останньої активності користувача (evdev, пасивно; підхоплює нові пристрої) |
| `MainLoop` | консольний режим: цикл дій, автопауза, логи |

### `activity_imitator_gui.py`

| Клас | Призначення |
|---|---|
| `Settings` | налаштування користувача (JSON-файл) |
| `ImitatorWorker` | фоновий потік імітації: дії, розклад, автопауза |
| `SyntheticInputGuard` | ігнорує кліки й клавіші одразу після власних дій імітатора |
| `PowerRing` | велика кнопка-кільце з відліком |
| `StatusPill` | індикатор статусу |
| `Toggle` | анімований перемикач |
| `NoWheelSlider` | слайдер, що ігнорує колесо миші |
| `LogDelegate` | малювання рядка журналу |
| `LogList` | журнал із порожнім станом |
| `StatCard` | картка статистики |
| `MainWindow` | головне вікно, трей, стани |
